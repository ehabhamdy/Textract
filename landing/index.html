Security
YOUR SCREEN
STAYS
YOURS

TextExtractor was built with a deliberate design decision: no network requests, ever. There is no account, no API key, no telemetry. The app processes everything through Apple's on-device Vision framework and writes directly to NSPasteboard.

What that means in practice: a screenshot you take at 2am in a secure facility behaves identically to one taken at your desk. The data does not move.

  • ✓Apple Vision processes images in local memory — no disk caching of screenshots
  • ✓Screen Recording permission is scoped to the selected region only
  • ✓Temporary capture files are deleted immediately after OCR completes
  • ✓No analytics, no crash reporters, no external SDKs
  • ✓Open architecture — inspect it yourself
